Atif Ghani is a DevOps and Cloud Engineer based in Sialkot, Pakistan, with a strong track record in AWS infrastructure automation and secure architecture design. He has hands-on experience building production-grade cloud environments using VPCs, subnets, NAT gateways, and security groups to support workloads on ECS, EKS, and EC2. He is skilled in Infrastructure-as-Code, having built reusable Terraform modules for VPC, EKS, ECS, RDS, Lambda, IAM, S3, CloudFront, and Application Load Balancers.
At Skyloop Cloud in Istanbul, Atif implemented CI/CD pipelines using GitHub Actions and Jenkins, automating containerized builds and deployments to Amazon ECR with rolling updates. He deployed and managed EKS and ECS clusters (EC2 and Fargate), configuring autoscaling, ingress controllers, and service discovery for microservices running across multiple environments. He also provisioned and maintained Amazon RDS databases (PostgreSQL and MySQL) and developed serverless, event-driven systems using Lambda, API Gateway, and DynamoDB Streams. A notable area of his expertise is AWS IoT, where he designed solutions using IoT Core, Greengrass v2, and IoT FleetWise for secure telemetry and edge processing in connected devices and robotics applications.
In addition to his DevOps background, Atif has built strong MLOps capabilities through an applied project covering end-to-end machine learning workflows. He worked with Docker, Kubernetes, and KServe for cloud-native model inference, compared custom Flask-based model serving against managed KServe deployments, and implemented AWS SageMaker workflows with role-based access control. He also orchestrated ML training pipelines using Kubeflow and managed experiment tracking and model versioning with MLflow and DVC.
Atif holds a Bachelor of Science in Computer Engineering from Bahçeşehir University and is AWS Certified as a Developer Associate, with further certifications in Kubernetes on EKS, Azure DevOps, and MLOps. He brings together deep expertise in cloud infrastructure, automation, and machine learning operations, making him well-suited for roles in platform engineering, DevOps, and ML infrastructure.
